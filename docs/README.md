# go-webthings

Guides for building a website with go-webthings. You bring the templates and choose the modules; go-webthings runs the database, the admin, pages, media, languages and the modules.

These guides are also published at https://docs.gowebthings.com/go-webthings. The bundled modules are documented at https://modules.gowebthings.com.
